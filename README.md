# ShivarVaat – Photography Portfolio Website

## About the Project

ShivarVaat is a photography-themed website built using HTML and CSS. It features a sidebar navigation menu and a photography-inspired design.

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- Font Awesome

## Features

- Sidebar navigation menu
- Open and close menu functionality using CSS
- Social media icons
- Hover effects
- Photography-themed interface

## What I Learned

While building this project, I practiced HTML structure, CSS positioning, selectors, pseudo-classes, and hover effects.

One interesting part was creating the sidebar menu using a checkbox and CSS selectors without JavaScript.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
